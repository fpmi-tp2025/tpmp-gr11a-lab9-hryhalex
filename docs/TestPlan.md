## 2. Типы тестов

### 2.1 Модульные тесты (Unit Tests) - XCTest

| ID | Название | Что проверяет | Ожидаемый результат |
|----|----------|---------------|---------------------|
| UT1 | testExample | Работоспособность тестов | Тест проходит |
| UT2 | testDataManagerExists | Существование DataManager | DataManager не nil |
| UT3 | testSaveLoginState | Сохранение в UserDefaults | Данные сохраняются |
| UT4 | testLogout | Очистка данных при выходе | UserDefaults очищается |

### 2.2 UI-тесты (ручное тестирование)

| ID | Сценарий | Шаги | Ожидаемый результат |
|----|----------|------|---------------------|
| UI1 | Запуск приложения | Открыть приложение | Экран входа |
| UI2 | Успешная авторизация | Ввести логин/пароль → Войти | Список лекарств |
